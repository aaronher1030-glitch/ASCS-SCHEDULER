## 2. STRUCTURE & CONVENTIONS
* **Anti-Emoji Policy:** NEVER use emojis in markup or code. Replace symbols with high-quality icons or clean, unified SVG primitives.
* **Viewport Stability:** NEVER use `h-screen` for full-height sections. Use `min-h-[100dvh]` to avoid mobile layout jumps.
* **Grid over Flex-Math:** Use robust CSS grid systems (`grid grid-cols-1 md:grid-cols-3 gap-6`) instead of complex flex calculations.
* **Materiality:** Add subtle inner borders (`border-white/10` or dynamic border shades) and inset shadows to simulate refined, professional visual depth.
* **Tactile Feedback:** Apply spring transitions on button press (`scale-[0.98]`, `-translate-y-[1px]`) to give physical responses.
